## 线 2：AI 应用开发（重点重写）

### 先回答你的问题：是不是背背概念就行？

**不是。** 概念只占三成，七成是"能跑起来 + 能讲清为什么这么做"。

你以前项目是 vibe coding 出来的，后果就是**一追问就露馅**——四面问 ReAct 优缺点你答不上，就是典型：你知道这个词、也用过，但讲不出体系和对比。面试官问的是"你为什么这么切分""Top-k 为什么取 5""Agent 循环几步、超了怎么办"，这些背概念答不了，**必须自己做过才答得出**。

### 每个板块多大？要多久？

| # | 板块 | 时间 | 产出（不是笔记，是能跑的东西） |
|---|------|------|--------------------------|
| 1 | 大模型基础 + Prompt | 2–3 天 | 一套能用的 prompt 模板 |
| 2 | **RAG** | 1 周 | 一个能跑的 RAG 问答（用你博客做语料） |
| 3 | **Agent 框架 + Function Calling** | 1 周 | 一个能调 2–3 个工具的 Agent |
| 4 | **MCP** | 3 天 | 一个自己的 MCP Server |
| 5 | **Agent 范式 + Harness**★ | 1 周 | 能脱稿讲 ReAct + 6 种范式对比 |
| 6 | 综合项目 | 1 周 | 把上面串起来 + 一篇复盘 |

**合计约 4–5 周。** 不是 6 天背完，也不是学半年——每个板块 3–7 天，够你跑通一个最小可用的东西。

### 每个板块具体做什么

**板块 1｜大模型基础 + Prompt（2–3 天）**
- 学：token / 上下文窗口 / 温度 / 什么是 Embedding；Prompt 技巧（few-shot、CoT、结构化输出）
- 做：写 3 个 prompt 模板（信息抽取、分类、结构化输出 JSON）
- 验收：能说出"温度调高会怎样""上下文超了怎么办"；能让模型稳定返回可解析的 JSON

**板块 2｜RAG（1 周）**
- 学：切分 → Embedding → 存向量库 → 召回 Top-k → 重排 Rerank → 拼 prompt 生成 → 效果评估（7 步）
- 做：用你 `baojian-notionnext-blog` 的文章做语料，做一个"问自己博客"的问答
- 验收：能画出 7 步流程图；说出每步的坑（切分多大、Top-k 取几、为什么需要重排）

**板块 3｜Agent 框架 + Function Calling（1 周）**
- 学：LangChain 五件套（PromptTemplate / Chain / Tool / Agent / Memory）；Function Calling 的工具 schema 协议
- 做：写一个 Agent，能调 2–3 个工具（比如查天气 + 查日历 + 写文件）完成任务
- 验收：能说出 Agent 四大组件（LLM+工具+记忆+规划）；能手写一个 tool 的 JSON schema

**板块 4｜MCP（3 天）**
- 学：MCP 协议（tools / resources / prompts、JSON-RPC、stdio/SSE）；看 [modelcontextprotocol.io](https://modelcontextprotocol.io/)
- 做：写一个自己的 MCP Server（比如暴露"读飞书文档""写飞书表格"两个 tool）
- 验收：能讲清"**为什么需要 MCP**"（不改造源系统就能把企业系统接进 Agent）

**板块 5｜Agent 范式 + Harness（1 周）★ 面试最常考**
- 学：ReAct（Thought→Action→Observation）+ 其他范式对比（CoT / Plan-and-Execute / ReWOO / Reflexion / Multi-Agent）；Harness = Model + Harness 理念
- 材料：`06-面试准备/秋招面试准备/美团-AI产品Builder/08-技术交叉面深度备战.md` **第九节**（已写好，直接背）+ 仓库 `07-AI应用工程师知识/概念笔记/Agent`
- 验收（4 条，逐条过关）：
  1. 30 秒说清 ReAct 是什么
  2. 说出 ReAct 的 5 个缺点
  3. 说出 ≥4 种其他范式 + 什么时候用哪个
  4. 接回自己项目：飞书 PM Agent = ReAct（4 步上限治缺点）；FitGenius = 单次结构化输出（不需要循环）

**板块 6｜综合项目（1 周）**
- 做：把 RAG + Agent + MCP 串成一个小东西（比如"问我项目文档的智能助手"）
- 写：一篇复盘放 `07-AI应用工程师知识/`，写清"为什么这么设计、踩了什么坑"
- 这就是下一场面试的新弹药

### 每个板块的通用三步（照这个循环）

1. **读**：官方文档（LangChain / LlamaIndex / MCP 官网）或仓库笔记 —— 只求搞清"这东西解决什么问题"
2. **做**：跑通最小 demo，**自己敲，不许 vibe coding**（这是你这次要补的短板）
3. **讲**：让 AI 当考官考你 —— "你问我 RAG 七步，我口答，你挑错"。讲不清的地方回去补，补完再讲

### 时间怎么排（两条线并行）

| 时段 | 内容 |
|------|------|
| 上午 | 算法 / Python（1.5–2h） |
| 下午 | AI 应用开发（1.5–2h）：按板块 1→6 顺序推进 |
| 晚上 | 雅思（自理） |

板块顺序**严格按 1→6 走**，不要跳。前面的板块是后面的基础（不懂 Function Calling 就做不了 Agent，不懂 Agent 就讲不清 ReAct）。
