## 三、按「以前没学精」的视角，重点复习清单

下面这些是我从 notebook 里抽出来的高频考点，**赌你以前就是这些地方卡住的**。逐条敲代码验证，别只看。

### 第 1 章 · print 的两个隐藏参数

- `print()` 默认结尾换行，控制它的参数是 `end`。
- 一次输出多个值默认用空格分隔，控制它的参数是 `sep`。
- `print()` 还能做加法、乘法（数字相加 / 字符串重复拼接）。

自测：让 `print(1, 2, 3)` 输出成 `1-2-3` 并且不换行，怎么写？（答案：`print(1,2,3, sep='-', end='')`）

### 第 2 章 · 整除与取余

- `//` 是向下取整的除法，`%` 是余数。
- 这俩是后面判断奇偶、进制转换、循环取位的基石。

自测：`7 // 3`、`7 % 3`、`-7 // 3` 分别是多少？（负数那个是坑，答案是 2、-3，Python 的 `//` 向下取整不是向零取整。）

### 第 3 章 · 变量与函数（最该重学的一章）

变量本质：**变量是一个名字，指代一段数据**，用 `=` 赋值。新值会覆盖旧值，且新值类型可以和旧值不同。

命名规则：字母或下划线开头；只能含字母、数字、下划线；大小写敏感；避开保留字。

函数两块：
- `header`：`def 函数名(参数):`，以冒号结尾。调用时参数作为变量传给 body，可多个、可为零。
- `body`：缩进的语句；不缩进就结束；一般用 `return` 返回值（非必须）。

自测：写一个 `double(x)` 返回 `2*x`；再写一个无参数、无 return 的函数。搞清楚「返回值」和「打印出来」是两码事——这是新手第一大坑。

### 第 4 章 · 条件判断

`if / elif / else`，条件后面冒号，分支要缩进。教程用「更有意思的例子」引导，配合第 3 章函数一起练。

### 第 5 章 · 循环

- `for i in range(n)` 重复 n 次；`range(m, n)` 从 m 到 n-1；第三个参数是步长。
- 省略第一个参数默认从 0 开始；步长可以是负数，用来倒着数。
- 循环嵌套，配合 `*` 打印图形是经典练习。
- 教程强调「不用循环也能做同样的事」——建立「一件事有多种写法」的意识。

自测：只用一行求 1~100 的奇数和；再倒着打印 10 到 1。

### 第 6 章 · 字符串（111~152 个 cell 的大章，别跳）

- 四种引号：`'`、`"`、`'''`、`"""`；三引号常用来写 docstring。
- 为什么需要两种引号：字符串里要包含另一种引号时不用转义。
- 转义序列：前面带 `\`，如 `\n` 换行，**只算一个字符**。
- `repr()` vs `print()`：前者给出「计算机可读」的形式（带引号、转义可见），后者给人看。这是后面 `__repr__` 的伏笔。

自测：打印一句含双引号的话；说出 `repr('a\nb')` 和 `print('a\nb')` 输出的区别。

### 第 7 章 · 列表与元组

- 创建、混装不同类型、`[0]*n` 造全零列表。
- 列表可比较（字典序）、有一堆内置方法（append/pop/sort 等，自己敲一遍）。
- **列表可变、元组不可变**——这是后面理解「哪些类型能当字典 key」的前置。

### 第 8、9 章 · 集合与字典

- Set：无序、去重，`in` 判断成员快，支持并交差。
- Dict：key → value 映射，空字典 `{}`。**key 必须可哈希**（第 11 章 `__hash__` 会回扣这里）。
- 这两章 cell 数少（33、38），但概念密度高，是面试常客。

### 第 10、11 章 · 面向对象（从「用」到「造」）

Part 1：
- Method vs Function：写在类里叫方法，独立叫函数。
- Class vs Instance：类是图纸，实例是按图纸造出来的对象。
- 写类、`__init__` 构造函数。

Part 2（特殊方法，是 Python 的精髓）：
- 类型检测：`type()`、`isinstance()`。
- `__eq__`：相等判断；`__str__` / `__repr__`：转字符串（repr 要机器可读）。
- `__hash__` 与 `__eq__` 配对：想让对象能放进 set / 当 dict key，就得实现这俩，且相等的对象必须哈希值相同。

自测：写一个 `Point(x, y)` 类，实现 `__eq__` 和 `__repr__`，然后把它放进 set 里验证。

## 四、和 AI / 大模型路线怎么接上

你主路线是 happy-llm → hello-agents，Python 是工具层。复习时心里带着这个目标，知道哪些地方未来会用：

- **第 3 章函数**：以后写 LLM 调用、RAG 的 `get_chunk()`、GRPO 的 reward 函数，全是函数定义与参数传递。
- **第 5 章循环**：batch 训练、逐 token 生成、rollout 状态机，本质都是循环。
- **第 7、9 章 list/dict**：消息历史 `history = [{'role':'user','content':...}]` 就是「列表套字典」，RAG 的 `document.json` 就是字符串列表。
- **第 10、11 章 OOP**：hello-agents 的自研框架 HelloAgents、各种 Agent 类，都靠类和继承组织。

所以别把 Python 当独立科目学——每学一个语法，就想「这个在 RAG 代码里长什么样」。你对着 happy-llm 的 `docs/chapter7/RAG/*.py` 看，会发现全是你正在复习的东西。
