## 二、知识点清单（面试官可能从任意角度问，先认脸）

### A. Python 后端（教程 03/04）
- [ ] 装饰器、上下文管理器、生成器、异步 async/await
- [ ] 类型提示、dataclass、pydantic
- [ ] 什么是后端 / Web 框架；FastAPI vs Flask
- [ ] 路由、请求/响应模型、依赖注入 Depends、异常处理、CORS
- [ ] RESTful、HTTP 状态码（200/401/422/500）

### B. AI 工程范式（教程 05，最核心）
- [ ] Prompt：System/User、Few-shot、CoT、结构化输出、温度/max_tokens
- [ ] RAG 完整流程：切分→Embedding→向量库→召回→重排→生成
- [ ] Agent 五大机制：状态机 / 记忆 / 任务规划(ReAct) / 工具调用 / 多智能体
- [ ] Function Calling 协议（工具 schema 描述、错误处理）
- [ ] LLM API 调用：流式、多轮 history、Token 成本

### C. 后端基础组件（加分项，能说"是什么、干嘛用"即可）
- [ ] 消息队列（Kafka/RabbitMQ/Redis Stream）：异步、解耦、削峰
- [ ] 缓存（Redis）：Cache-Aside、TTL
- [ ] 数据库：MySQL/PostgreSQL 基本 SQL、索引；向量库 FAISS/Milvus
- [ ] WebSocket / SSE：流式输出

### D. 效果评测与优化（JD 第 4 条）
- [ ] 维度：准确率、响应时延、Token 成本、用户满意度
- [ ] 方法：A/B 测试、人工评估集、自动化测试集
- [ ] 优化：Prompt 迭代、模型选型、缓存、并发异步

### E. 框架（加分项，过概念）
- [ ] LangGraph（状态机原生）、AutoGen（多智能体）、Dify（低代码工作流）、CrewAI、MetaGPT

## 三、高频面试题（学完教程后自问自答）

### Python / 后端
1. Python 异步编程用过吗？asyncio 怎么用？LLM API 调用为什么常用异步？（答：等模型返回不阻塞，见 03 §2.6）
2. FastAPI 和 Flask 的区别？为什么更多人选 FastAPI？（答：异步+自动文档+类型安全，见 04 §1）
3. 怎么设计一个高并发 LLM API 服务？（异步 + 限流 + 缓存 + 队列）
4. 怎么保证接口稳定性？（异常处理 + 重试 + 降级 + 监控，见 04 §3 代码）

### AI 工程
5. **RAG 完整流程是什么？向量检索怎么做？**（必问，按 05 §2 答）
6. **Agent 和单纯调 LLM 的区别？Agent 核心机制？**（必问，按 05 §1 答）
7. Agent 的 Tool Use 怎么设计？（Function Calling 协议、工具 schema、错误处理）
8. Prompt 工程常用技巧？（few-shot、CoT、结构化输出）
9. 怎么控制 LLM 成本？（模型分级、缓存、上下文压缩、batch）
10. **DeepSeek Harness 和 Codex Harness 区别？各适合什么场景？**（你的加分项，按 05 §3 答）
11. 为什么 2026 年行业说"Agent = Model + Harness"？（按 05 §0 答，展示前沿认知）

### 项目 / 场景
12. 你的项目管理智能体怎么设计的？（讲长城证券案例，按 `02-项目讲述-技术导向.md`）
13. 怎么评测一个 AI 应用的效果？（按 D 部分答）
14. 从 0 设计一个 AI 智能体系统怎么起步？（需求拆解 → 状态机 → 工具定义 → 评测）
15. 把 harness 知识和 TCL 光伏业务结合，说一段"为什么这个岗位适合我"。（按 05 §3.5 话术）
