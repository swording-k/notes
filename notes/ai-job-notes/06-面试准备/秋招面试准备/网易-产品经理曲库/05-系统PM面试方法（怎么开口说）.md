# 系统 PM 面试方法：怎么把框架变成嘴能说的话

> 你之前的问题是：「框架我有了，但面试官真问我『初衷是什么』『讲讲实习』，我不知道怎么张嘴。」这篇就是解决这个问题——教你怎么**现场组织语言**，配上 `02` 里的逐字稿一起用。

---

## 一、先搞懂：PM 面试到底在考什么（3 个维度）

面试官不是考你"背了多少名词"，他看三件事：

| 维度 | 他实际在判断 | 你怎么暴露 |
|---|---|---|
| **产品感** | 遇到陌生问题，能不能拆、能不能想场景 | 产品题（估算/设计/分析） |
| **逻辑与表达** | 讲话有没有结构、有没有数据、清不清晰 | 你讲项目、讲经历的方式 |
| **真实性** | 项目是不是真做过、想得深不深 | 被追问细节时不慌、答得上 |

你技术底子好（FitGenius、PM Agent 都是真做的），**真实性这一项你天然占优**。短板在"逻辑与表达"——也就是"讲得不像培训过的人"。这篇专治这个。

---

## 二、系统答题法：把任何问题变成「开口说的 3 步」

不管面试官问什么，你都走这三步，练熟了就是肌肉记忆：

### 第 1 步：接话定调（前 5 秒，最重要）
先确认/复述问题，再给一句**总括**，把节奏拿回来。
- 问初衷 → "FitGenius 的初衷啊，其实特别直接……"
- 问实习 → "我实习主要有两段，一段在长城证券、一段在美团，我先从长城证券讲起……"
- 问产品题 → "这个问题我会从用户、场景、价值三个角度看……"

❌ 错误：沉默 3 秒然后蹦名词。"呃……就是 schema 约束、白名单……"
✅ 正确：先接话、定调，给自己 5 秒组织时间。

### 第 2 步：套「故事骨架」但用嘴说（中间 90 秒）
框架（背景/目标/决策/结果/复盘）是**写给人看的**，你说的时候要变成**一串有起承转合的话**：

> 背景（一句话把人拉进场景）→ 目标（我要解决的具体问题）→ **"所以我当时做了三件事"**（逐条口语化展开）→ 结果（一句定性/定量）→ 复盘（半句，显思考深度）

关键：**每个"我做了 X"后面必须跟"因为 Y"**。培训班的人和被刷的人最大区别就在这——前者说"为什么"，后者只说"做了什么"。

### 第 3 步：收尾抛钩子（最后 10 秒）
讲完别停，主动抛一个面试官**可能追问**的点，把节奏控在你手里：
- "其实这个项目给我最大的 PM 启发是：AI 是一种能力供应链，要稳定化才能用上。"
- "这段经历让我确认了一件事：我更适合做能把技术和业务落地连起来的产品。"

> 钩子的作用是：把面试官的下一个问题，引向你**准备好的地方**。

## 三、万能填空模板（任何项目都能套，熟背）

把下面这段话背下来，面试前把【括号】换成你的项目，就能当场拼出一段完整讲述：

> **【项目名】** 是 **【一句话是什么】**。
> 当时做它是因为 **【背景痛点】**。
> 我定的目标是 **【具体目标】**。
> 围绕这个我做了几件事：第一 **【行动1 + 因为…】**，第二 **【行动2 + 因为…】**。
> 最后 **【结果】**。
> 复盘的话 **【反思】**。
> 这个项目让我学到 **【一句 PM 启发】**。

例（FitGenius 填空）：
- 一句话：一个用大模型生成个性化健身计划的 iOS App
- 背景痛点：AI 生成不可控、格式错、崩，变不成稳定功能
- 目标：让 AI 输出可控、可解析、不崩
- 行动1+因为：强 schema+白名单，因为不能让模型自由发挥
- 行动2+因为：自写括号匹配兜底，因为现成框架不可靠
- 结果：解析从常失败到稳定可解析
- 反思：该做成可配置模板复用
- 启发：AI 是能力供应链，要稳定化

## 四、4 个说话习惯（培训班 vs 你之前的讲法）

| ❌ 你容易犯的 | ✅ 改成这样 |
|---|---|
| 念名词堆："我做了 schema 约束、白名单、兜底" | 说人话+说为什么："我给它画了个框只让它在框里生成，因为模型自由发挥就崩" |
| 只说"做了什么" | 每个决策带"因为"——"我设温度 0，**因为**要同样输入同样输出" |
| 结果空泛："效果很好" | 量化或对比："从经常失败 → 稳定可解析" |
| 讲完就停，等面试官问 | 主动抛钩子，把下一个问题引向你准备好的点 |

---

## 五、不会的题怎么救（别慌，有套路）

**产品题不会（估算/设计/分析）**：
1. 先说框架："我会从用户、场景、价值三个角度看"
2. 再填内容，不会就**假设**："假设目标用户是 18–25 岁学生，那……"
3. 卡住就说："这个问题我不熟，但我的拆解思路是……"——面试官看的是拆解能力，不是标准答案

**行为题没对应经历**：
- 别编，用你项目里的**片段**凑（"虽然没正式带过团队，但我在 PM Agent 项目里协调过需求拆分……"）
- 诚实 + 关联，比瞎编安全

## 六、怎么练到脱口而出（训练法）

1. **念稿 3 遍**：把 `02` 的 6.1–6.4 逐字稿念 3 遍，录下自己听，改掉拗口和"呃"
2. **填空自测**：用第三节模板，把美团、飞书 PM Agent 也各填一遍说出来（不写，直接说）
3. **模拟追问**：让朋友/AI 追问"最大的困难""重来会改什么"，用 6.4 接话
4. **当天 checklist**：进场前过一遍——接话定调 ✓ / 每点带"因为" ✓ / 结尾抛钩子 ✓

## 七、PM 行话工具箱与场景化公式（这层壳才是"培训过"和"没培训"的分界）

前面几节解决的是"逻辑与表达"——把骨架讲成故事。但培训班出来的人，还会再裹一层**行业外壳**。这一节给你工具箱，配合 `02` 第四节的对照一起看。

### 7.1 场景化公式（把"痛点"讲成"画面"）

不要说："用户有 XXX 的痛点。"
要说：**[具体角色] + [具体时刻/触发] + [具体动作] + [具体代价/情绪]**

- 裸："投顾要在多个系统间切换，效率低。"
- 加壳："想象一个工作 3 年的投顾小王，**周一早会前**，要在企微、OA、还有两个业务系统里**翻找客户上周提的需求**，来回复制粘贴半小时，还经常漏掉一条——**月底复盘发现就是因为这条漏了，被领导点名**。"

→ 一句话：先给一个**人**，再给一个**时刻**，再给一个**动作**，最后给一个**代价**。面试官脑里立刻有画面，这就是"场景感"。

### 7.2 术语工具箱（分类，挑你真懂的用）

| 类别 | 词（你说出来就是"行内人"） |
|---|---|
| **用户研究** | 用户分层、用户画像、用户旅程地图、痛点/痒点/爽点（阿里框架）、用户访谈、场景 |
| **策略/增长** | 北极星指标、第一性指标、闭环、飞轮、双边市场、网络效应、护城河 |
| **指标** | 留存（次留/7 留/30 留）、转化、触达、渗透率、DAU/MAU、GMV、ARPU、LTV、CAC |
| **决策/迭代** | KANO 模型、MVP、敏捷迭代、取舍标准、ROI、灰度发布、A/B |
| **产品表达** | PRD、需求评审、信息架构、用户体验五要素（战略/范围/结构/框架/表现）、泳道图 |

### 7.3 框架命名（点出"我用的是哪个方法论"）

讲决策时顺嘴点一个名字，显出"我是按方法论做的，不是拍脑袋"：
- 排优先级 → "用 **KANO 模型**过了一遍"
- 早期验证 → "先做 **MVP** 在一个团队试点"
- 讲系统目标 → "这个产品的**北极星指标**是 XXX"
- 拆用户路径 → "我画了张**用户旅程地图**"
- 讲平台定位 → "我的定位是**连接层/工具层**，不是替代原有系统"

### 7.4 数据锚定原则

每讲一个功能/决策，**最好跟一个数字当证据**。你已有的可防御数字：
- 长城证券：提 8 项建议、5 项入 v3 需求池、MVP 被 2 个团队用、迭代 5 版 PRD
- FitGenius：30+ 种子用户（⚠️ 建议补一个内测留存/下载数字，否则"北极星=周留存"没锚点）

### 7.5 使用边界（很重要，别过头）

- **别背词典**：挑 3–4 个你真懂的用熟，比堆 10 个生词自然；生词说不顺，面试官反而觉得在表演。
- **AI 产品 / Builder 岗（如美团）**：你的"自然 + 技术深度"其实更吃香，**别硬塞行话**——那种岗的面试官自己就是做 AI 产品的，听得出表演。
- **纯互联网 PM 岗（如网易曲库）**：行话 + 场景是**加分项**，因为面试官就是这么讲的，同频才显你"是自己人"。
- **数据锚定**：没数字就讲"定性反馈"（如"30 人内测驱动了后续迭代"），别编百分比。

---

## 八、一句话收尾

框架是骨架，这篇是"怎么把骨架长出血肉"。**方法就一句：接话定调 → 用嘴把骨架讲成故事（每点带因为） → 抛钩子**。再裹一层外壳（场景化 + 行话 + 数据锚定）就是"培训过的人"。配合 `02` 的逐字稿和**第四节的加壳对照**念熟，网易这种纯 PM 岗你讲出来就是同频的。
