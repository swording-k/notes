# 网易曲库 PM · 高频题型模板与话术

## 一、产品感题（最可能考）
模板：**定义 → 用户/场景 → 方案 → 验证 → 优先级**
示例：「设计一个帮助独立音乐人管理作品的曲库功能」
- 定义：独立音乐人作品散、版权乱、曝光难
- 用户：独立音乐人、小厂牌
- 方案：一键入库 + 自动元数据 + 版权状态看板 + 分发建议
- 验证：内测 N 人、入库时长、分发转化率
- 优先级：先一键入库（最高频痛点）

## 二、数据分析题
模板：**建指标 → 拆维度 → 假设 → 验 → action**
示例：「曲库覆盖率下降怎么分析」
- 指标：曲库歌曲数 / 目标曲数、新增入库速率
- 维度：分版权方 / 分语种 / 分年代
- 假设：某大版权方下架 / 录入人力不足
- 验：看哪个维度掉
- action：补录 / 谈版权 / 自动化

## 三、估算题
模板：**口径 → 因子 → 假设 → 算 → 校验**
示例：「网易云音乐日均新增歌曲量」
- 口径：平台每天新入库歌曲
- 因子：独立音乐人上传 + 版权方批量 + UGC
- 假设：X 万音乐人 × 月产 Y + 版权 Z
- 算：…
- 校验：对比公开曲库总量

## 四、行为 / 项目深挖（用 02 文档的叙事主线）
高频：
- 最大困难、和研发冲突、最失败项目、为什么选产品
- 必练：「你为什么从工程 / Builder 转产品？」
  → 答：「技术能写 Demo 验证方案，但更想决定做什么、为谁做——所以往产品走。我的技术背景是差异化优势，不是包袱。」

## 五、反问环节（准备 3 个）
- 曲库团队现在最大的业务挑战是什么？
- 这个岗位 1 年内的核心目标？
- 团队怎么看 AI 对曲库运营的影响？
