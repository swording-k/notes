# 华为 · AI应用开发工程师 · 调查与机试备战

> 2026-09-16 调查。结论：**值得投 + 现在就开始准备机试**。

## 一、公司体量（比美团高一级）

- 华为 **19.7 万员工**，全球 ICT 龙头、全产业链科技巨头，**非上市**（不需要融资），抗风险极强、几乎不裁员。
- 研发总部：**深圳坂田 + 东莞松山湖**（"华为小镇"），另有上海/西安/成都/杭州/南京/北京等十大研究所。
- 对比美团（约 4600 亿港元市值）：华为是更"硬核"的科技巨头，**简历镀金价值极高**。

## 二、岗位匹配度（高）

校招 AI应用开发工程师 JD 原话：
> "主要负责 AI 技术的业务场景落地与功能开发，基于现有大模型及 AI 能力，完成智能化功能搭建、场景适配与应用迭代。岗位偏向工程落地与业务赋能。"

- 这正是你的背景：AI 产品/应用落地、工程+产品复合。
- 华为 AI 平台：昇腾、盘古大模型、华为云，技术底座比美团 AI 直播/商家 Agent 更硬。

## 三、Base 城市（对你最大利好）

工作地点可选：**深圳、成都、上海、东莞、杭州、西安、北京、南京**。
- 你首选深圳？**华为深圳坂田总部=全球研发中心**，城市解比美团（北京总部、深圳名额不确定）清楚得多。
- 投递时 base 填"深圳/东莞"优先级最高。

## 五、工作强度（重要权衡，远高于美团）

- 研发核心部门 **995 标配、项目期 996/9116（9:00–23:00 单休）**，月加班 80–120 小时。
- **无加班费**，靠夜宵/调休补；末位淘汰约 10%。
- 用青春换钱+镀金，能否扛要想清楚。

## 六、机试结构（你说对了，确实难）

- **选择题**：20 道（15 单选 + 5 多选），考大模型概念、机器学习理论、PyTorch 常用 API、简单数学计算。
- **编程题**：3 道，分值约 150 + 300 + 150（或 300），难度**中等到困难**。
- 考点分布（真题回溯）：
  - 动态规划（二维 0/1 背包、编辑距离类）
  - BFS / DFS（最短路径、迷宫类）
  - 图论（欧拉路径/字典序最小序列、拓扑）
  - 排序 / 贪心（加权中位数、曼哈顿距离）
  - RNN / 序列建模（AI 方向专属，较硬）
- 语言支持：C / C++ / Python / Java，**可用本地 IDE**（提前调好环境）。
- AI 方向统一一套题，**不区分部门**。
- 难度有波动：有人遇"很简单场"（单调队列/爆搜/编辑距离），有人遇"死磕场"（综合图论+背包）。但整体比中小厂难一截。

## 七、机试备战计划（现在就开始）

1. **选择题补强**（1–2 天）：过一遍机器学习基础（过拟合/正则、损失函数、评估指标）、Transformer/Attention 概念、PyTorch 常用 API（`nn.Module`/`DataLoader`/`tensor` 操作）。
2. **编程题刷题**（重点，1–2 周）：
   - 死磕 **动态规划**（背包、子序列、编辑距离）；
   - 练 **BFS/DFS** 模板题（迷宫最短路、连通块）；
   - 图论补 **欧拉路径（Hierholzer）/拓扑排序**；
   - 每天卡 **2 小时连做 3 题**模拟真实机试节奏。
3. **平台**：牛客搜"华为机考/华为笔试"真题，按 AI 方向套卷做。
4. **环境**：本地装好 Python/C++ 编译环境，机试允许本地 IDE，提前适应。

## 八、决策结论

**值得现在准备机试 + 投递**。理由：深圳 base + 硬核技术履历 + 巨头背书，对你可能比美团更优；与美团 offer 进程不冲突，可保底可谈薪。代价是本科起薪可能略低 + 强度显著更高——若你最看重"深圳 + 技术镀金"，华为优先；若最看重"钱多+相对不卷"，美团优先。
