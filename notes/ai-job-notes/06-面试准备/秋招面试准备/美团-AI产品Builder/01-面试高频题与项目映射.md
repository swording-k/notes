# 美团 AI产品Builder · 面试高频题 + 你的项目映射

> 每题给：考察点 / 你可用的项目弹药 / 注意点。配合 `02-项目讲述-产品导向.md` 一起看。
> 标注"必问"的是该岗高频，优先练熟。

## Q1 1 分钟自我介绍【必问】
- **考察**：是否清晰、是否对岗。
- **弹药骨架**：中南 27 届信息安全本科 + 长城证券产品实习 + 独立 0→1 AI 产品（FitGenius）+ 开源协作（Atoll collaborator）+ 技术底子（能自己写 Demo / Agent）。
- **收尾句**："我看到这个岗强调'自己用 AI 把产品做出来'，我正好一直在这么做。"
- **注意**：用"做了什么产品、解决了谁的问题"开头，别背工程细节。

## Q2 为什么想做 AI 产品 / 你怎么看 AI 原生产品
- **考察**：兴趣真实性 + 思考深度。
- **弹药**：从长城证券内部协同产品 → 飞书智能体 → FitGenius，都是"AI 嵌入工作流"的实践。观点："AI 原生不是加个 chatbot，而是把任务链路重构成'人 + 模型'协作。"
- **注意**：要有观点 + 例子，别空谈。

## Q3 讲一个你从 0 到 1 做的 AI 产品【必问】
- **考察**：产品闭环能力、踩坑、决策。
- **弹药**：FitGenius（见 02-A）。
- **注意**：用 STAR，重点讲"怎么定义问题、怎么验证、怎么迭代"，不是讲 SwiftUI 怎么写。

## Q4 你做过 Agent 吗？怎么设计的【必问】
- **考察**：是否真懂 Agent 产品设计（不是只会调 API）。
- **弹药**：飞书项目管理智能体（领域模型 需求≠任务 M:N + RTM + 5 版 PRD + 2 团队落地）。
- **注意**：讲"我对 Agent 循环 / harness 的理解 + 怎么约束它只干业务内的事（白名单）"——这是你比纯产品候选强的点。

## Q5 你怎么用 AI 工具提升自己效率【必问，JD 硬要求】
- **考察**：是否真是"AI 工具高频使用者"。
- **弹药**：NotionNext 博客 + wechatsync 一键多平台分发、个人 AI 工作流、用 AI 写 PRD / 做原型。
- **注意**：要具体（用了什么工具、省了什么），别只说"我用 ChatGPT"。

## Q6 现场场景题：给美团 XX 设计一个 AI 功能【必问，高频！】
- **考察**：需求拆解 + 模型边界判断 + 交互设计 + 验证意识。
- **方法论（背熟）**：① 锁定用户 & 真实痛点 → ② 判断模型能力边界（什么能做 / 会翻车）→ ③ 设计交互（人何时介入、如何可信）→ ④ 定义验证指标（怎么算解决问题）→ ⑤ 小步快跑上线实验。
- **弹药**：套你飞书智能体"从痛点 → 领域模型 → MVP → 两个团队试用"的路径。

## Q7 Prompt 设计经验
- **考察**：是否真动手调过。
- **弹药**：FitGenius 用 system prompt 强制只返回 JSON → 解析 → 驱动 App；飞书 agent 的 tool 描述与重试。
- **注意**：讲"为什么这么写、翻车过什么"（如格式不稳定 → 加约束 + 校验层）。

## Q8 你怎么判断一个 AI 功能是否真解决问题（JD 要求⑤）
- **考察**：用户体验敏感度、不盲信 AI。
- **弹药**：FitGenius 动作识别"评分反馈"是否真帮用户练准——靠种子用户反馈迭代；长城证券"缩短上手周期"靠操作手册被纳入 onboarding 材料验证。
- **注意**：强调"看用户是否持续用、是否真完成目标"，不是看 demo 炫不炫。

## Q9 模型能力边界你怎么理解
- **考察**：是否清醒，不神话 AI。
- **弹药**：幻觉、长上下文丢失、多模态误判、成本 / 延迟；对应你设计时的兜底（白名单、人工确认、校验层）。

## Q10 你最大的产品取舍 / 失败
- 准备一个真实故事（如 FitGenius 先砍掉某功能先做核心闭环；或飞书智能体先只做 MVP 不贪全）。

## 附：你 vs 纯产品候选的差异化武器
- 你能**自己写 Demo / Agent**（多数产品候选不会），直接命中亮点③。
- 你懂 **Agent 架构 / harness / 模型边界**，聊技术不虚，能和算法 / 研发对等对话。
- 你有**真实从 0 到 1 落地 + 开源协作**证据，不是纸上谈兵。
