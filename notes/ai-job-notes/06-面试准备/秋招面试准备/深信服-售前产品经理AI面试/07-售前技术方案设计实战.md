# 07-售前技术方案设计实战（完整流程 + 可组合产品 + 没经验怎么圆）

> 用途：06 只讲了"一句话定义 + 场景轮廓"，这份把它拆成**你真去上班会怎么干活**的全过程，专门防"你没垂直实习经历、怕被问住"。
> 核心心法先记住：**售前不是写代码的人，是"翻译 + 组合"的人**——把客户模糊的「我要安全 / 要上云」翻译成可落地、可报价、合规达标的方案，并让客户相信能实现。

---

## 一、完整闭环：一个技术方案是怎么被"做"出来的

用 **某三甲医院要过等保三级 + 防勒索** 这个真实感最强的例子，串起全链路。注意：你（售前）不是孤军作战，是**和销售（客户经理）、交付（实施）、有时还有售前售后的技术专家**配合。

```
线索 → ①初访调研 → ②写方案建议书 → ③宣讲+演示 → ④POC验证 → ⑤投标/商务 → ⑥签单 → ⑦交付
        （跟销售去）  （回公司核心产出） （回客户现场）  （大单才有）  （技术标你写） （你退出）
```

### ① 初访调研（第一次见客户，你跟着销售去）
- **目的**：搞清楚四件事——**现在有什么、怕什么、要什么、钱多少**。
- **调研清单**：
  - 现状：现有网络拓扑？已经买了哪些安全设备（是不是已经有竞品，比如奇安信/启明星辰）？
  - 痛点：是被勒索过要加固？还是合规检查逼着过等保？还是领导要上云？
  - 决策链：谁拍板（信息科主任 / 分管院长 / 采购办）？预算谁批？
  - 约束：预算区间？工期？是否必须信创 / 国产化？
- **关键认知**：你问的不是纯技术问题，是「业务 + 合规 + 预算」三件套。客户不懂技术术语，你要会听"业务语言"→转成"技术语言"。

### ② 写《方案建议书》（回公司，售前最值钱的活）
一份标准方案建议书 = 7 个模块，**这是面试被问"怎么设计"时的标准答案骨架**：
1. **项目背景与现状**：客户现在啥样（从①调研来）
2. **需求分析**：对照等保 2.0 三级条款**逐条**列要求（比如"应采取入侵防范手段"→对应下文的 AF）
3. **产品组合与方案设计**：用哪些深信服产品、怎么串（见第二节矩阵）
4. **部署架构图**：画拓扑——互联网出口放 AF、内网终端装 EDR、核心区上态势感知、业务系统跑在超融合上
5. **合规映射表**：每条等保要求 → 对应哪个产品 / 哪个功能（证明"买了就能过关"）
6. **建设价值 / ROI**：为什么值得花这个钱（防一次勒索可能损失几百万）
7. **商务报价**：产品清单 + 实施服务 + 年度维保

### ③ 宣讲 + 演示（再回客户现场）
- PPT 讲方案，重点讲"**为什么这么组合**"（不是堆产品，是对应他的痛点）
- **演示**：现场用 AF 拦一个攻击样本、EDR 查杀一个勒索病毒样本，让客户"眼见为实"
- 难点：面对的可能是**非技术决策人**（院长），你要把技术翻译成"他能听懂的业务价值"

### ④ POC（概念验证，大单 / 谨慎客户才有）
- 客户说"光讲不行，你部署一套我看看效果"
- 你在客户环境小规模部署，跑真实攻防，出 POC 报告
- 这是售前和技术支持（交付前置）的配合点

### ⑤ 投标 / 商务谈判
- 政府 / 国企走**招投标**：你写**技术标**（方案部分），销售写商务标（价格 / 资质）
- 私企直接谈：你根据客户预算**砍 / 加产品组合**（见下"预算砍半怎么办"）
- 核心能力：把技术方案翻译成"客户愿意买单的价格"

### ⑥ 签单 → ⑦ 交付
- 签完单，**交付 / 实施团队进场真去加固**，售前退出转下一个商机
- 好售前会回访：方案落地了吗？客户满意吗？（为复购 / 扩单埋点）

## 二、"方案都有哪些可以组合的"——产品矩阵（重点背）

深信服方案 = **从下面三条产品线里挑模块拼**。这是你被问"怎么组合"时的弹药库：

### 智安全（网络安全线）
| 产品 | 干什么 | 对应痛点 |
|---|---|---|
| **AF 下一代防火墙** | 网络边界防护，拦攻击 | "边界没防护" |
| **EDR 终端检测与响应** | 电脑 / 服务器终端防勒索、查杀 | "终端裸奔" |
| **态势感知（SIP / SecOps）** | 全网安全可视化、威胁狩猎 | "出事了不知道" |
| **WAF** | 护网站 / 业务系统 | "对外系统被刷" |
| **aTrust 零信任** | 替代传统 VPN，"持续验证才放行" | "远程接入不安全" |
| **数据安全 DSG** | 防泄露、脱敏 | "怕病人数据外泄" |
| **安全 GPT / MSS 托管** | AI 驱动检测、7×24 托管 | "没安全运维人力" |

### 信服云（云计算线）
- **超融合 HCI**：服务器 + 存储 + 网络虚拟化合一，是医院 / 企业核心系统上云的底座
- **桌面云 aDesk**：办公桌面云化，集中管控（医生工作站）
- **托管云 / 私有云**：不想自建机房的单位选托管

### 信锐技术（基础网络 / 物联网线，深信服体系内品牌）
- 企业无线（医院 Wi-Fi 覆盖）、物联网（病房 / 安防物联）

### AI 能力（横切三条线）
- 安全 GPT、CoStrict AgentBuilder、AI 算力网关、DeepSeek 承载方案

### 组合示例（直接回答"怎么组合"）
- **医院等保三级 + 防勒索** = AF（边界）+ EDR（终端）+ 态势感知（监测）+ 数据安全（防泄露）+ 超融合（业务上云底座）
- **客户预算少** → 砍态势感知、先上 AF + EDR（保合规底线）
- **客户要上云** → 加超融合 / 桌面云
- 这就是售前的"**组合艺术**"：不是发明新产品，是把现有模块按客户痛点拼成一套说得出价值、报得出价的方案。

## 三、高频追问与应对（你怕"没经验"被问住，逐条备好）

**Q1：你没做过售前，怎么证明你能做方案？**
> 我做过 PM Agent 从需求到方案落地的全流程、在长城证券把投行 / 研究能力翻译成一线工作流——本质都是「把复杂专业能力变成对方用得上的交付物」。售前是把安全 / 云能力翻译成客户买单的方案，逻辑一模一样。我缺的是**行业业务知识**（医疗 / 金融 / 政企的合规细节），这部分入职后有 4 个月带薪培训 + 1v1 导师，我会按行业系统补。

**Q2：客户预算砍一半，你怎么办？**
> 先保**合规强制项**不能省（等保三级里 AF + EDR 是底线），非强制的监测类（态势感知）可后置；用 **MSS 安全托管**替代部分自建，降低一次性投入；先拿下小单建立信任，后续扩单。

**Q3：客户已经有竞品（奇安信 / 启明星辰）了，你怎么换？**
> 不硬换，找**差异化切入点**——深信服的"云网安一体化"（超融合 + 安全联动）、AI 安全 GPT 的托管能力，从单点短板做补充切入，再逐步替换。售前不靠贬低对手，靠"我这块你现有方案补不上"。

**Q4：你怎么快速搞懂一个陌生行业？**
> 三步走——① 查这个行业的**合规标准**（等保 / 行业规范）；② 看 1–2 个同行业标杆方案；③ 跟销售和客户聊。售前不是以"行业专家"起步，是以"**翻译 + 组合**"能力起步，行业知识是边做边补的。

**Q5：售前和售后（交付）到底什么区别？**
> 售前在**签单前**"画饼 + 证明能实现"（方案 + 演示 + POC），对客户负责拿单；交付在**签单后**"把饼做出来"（部署 + 加固），对系统负责落地。一个对"能不能卖出去"负责，一个对"能不能跑起来"负责。
