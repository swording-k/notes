# 常见 AI 面试题 + 结构化回答模板

> 通用公式：**结论先行（1句）+ 分点（2–3个，每点"我做了X→带来Y"）+ 收尾（1句）**。每题控制在 2 分钟内。

## Q1 自我介绍（必考）
- **考察**：匹配度、表达。
- **模板**：我是杨锟，中南大学 27 届计算机本科，目前在长城证券金融科技做产品实习，做过项目管理智能体 PRD 落地、从 0 到 1 一款 AI 健身 App FitGenius，并有 Atoll / Workisland 开源贡献。我理解售前 PM 是"把产品能力翻译成客户价值"，而我既有产品闭环经验、又有技术底子能和研发对齐，正适合这个岗。
- **关键词**：产品实习 / 智能体落地 / 技术底子 / 客户价值。

## Q2 为什么投深信服 / 为什么这个岗
- **模板**：结论——深信服是网络安全+云计算头部，售前 PM 能直接把 AI 安全产品（安全 GPT / AgentBuilder）讲给客户听，这正是我想做的。三点支撑：① 业务对口（我做过 AI 产品从 0 到 1）；② 平台大客户多（政企），成长快；③ 我能用技术背景把方案讲透。
- **别空谈"贵司厉害"**，要落到"我能贡献什么"。

## Q3 你的优缺点
- **优点**：把"产品+技术复合"讲成优点——能和技术 / 客户两边都对话。
- **缺点**：**真实但不致命**，且带改进。例："对 to B 政企安全行业的业务细节还在补，所以我正在系统学售前知识体系，用项目经验快速迁移"。别编"我太追求完美"这种。

## Q4 简历追问（项目为什么做 / 你负责什么 / 结果）
- **公式**：为什么做（痛点）→ 我负责（动作，用"我"）→ 怎么做（方案选择）→ 结果（真实事实，不编数字）。
- **例 FitGenius**：为什么做（健身人群缺个性化计划）→ 我负责（从调研、PRD、iOS 开发到上架全流程）→ 怎么做（用 LLM 生成结构化计划 JSON 驱动 App）→ 结果（已上架，独立闭环）。

## Q5 最有挑战 / 失败的一次（行为题）
- **公式**：问题—我做了什么—为什么—结果—下次怎么改。
- 别以"在大家共同努力下解决"结尾，要讲**你的判断与复盘**。

## Q6 情景题：客户说"你们产品不如竞品"怎么应对
- **模板**：先共情听诉求 → 再锚定客户真实业务场景（不是比参数而是比适配）→ 用我方优势场景（如安全 GPT 降噪、MSS 敢承诺兜底）做差异化 → 带回研发反哺。体现"售前=翻译+桥梁"。

## Q7 未来 3 年规划
- **模板**：1 年扎根售前能力（方案 / 演示 / 行业）→ 2–3 年能独立扛行业线 / 带小团队，成为既懂安全云产品又懂客户的顾问型售前。

## 保洁八大问映射（备用）
1. 最有成就感 → Q4 项目
2. 最失败 → Q5
3. 团队冲突 → 行为题
4. 领导力 → 开源协作 / 导师采纳建议
5. 创意 → FitGenius 从 0 到 1
6. 优先级 → 多线程实习 / 项目
（每题都套"结论 + STAR + 收尾"）
