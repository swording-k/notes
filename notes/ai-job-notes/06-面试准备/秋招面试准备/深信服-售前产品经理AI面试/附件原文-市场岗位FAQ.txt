1、To B 和 To C 市场工作内容的区别

客户与需求：To B 面向企业 / 机构，理性、群体决策、重长期价值与售后；To C 面向个

人，感性、冲动消费、重性价比与体验。

采购与周期：To B 大单、招投标、决策链长、回款周期长；To C 小额、即时决策、付款

即拿货。

工作重心：To B 做解决方案、行业经营、大客户关系、长周期项目；To C 做流量、爆款、

活动、用户增长与转化。

核心流程：To B 围绕 LTC（线索→回款）；To C 围绕 获客→转化→复购。

    3、售前产品经理 vs 互联网产品经理




   服务对象：售前 =To B 大客户；互联网 =To C 大众用户。

   核心目标：售前 =提高销售效率；互联网 =做产品迭代 / 生命周期。

   工作流：售前在 LTC（线索→现金）；互联网在 IPD（需求→开发→上市）。
   工作内容：售前 = 方案、标书、POC、技术交流；互联网 = 功能设计、原型、需求文档、

    迭代管理。

   能力偏向：售前偏行业 + 解决方案 + 销售协同；互联网偏用户体验 + 产品设计 + 研发

    协同。




    4、做好市场岗位最重要的是什么


1. 结果导向 + 经营思维：以订单 / 回款 / 增长为终点，像老板一样算投入产出。

2. 客户洞察 + 专业信任：懂行业、懂业务、懂产品，用专业影响决策。

3. 资源整合 + 协同能力：联动售前、研发、交付，打通全流程落地。

4. 抗压韧性 + 持续学习：适应长周期、高目标、新知识快速迭代。




    5、市场岗位最难的地方

   长周期 + 高不确定性：项目跟进数月，多次被拒，结果滞后难量化。

   决策链复杂：要搞定使用者、采购、管理层、决策者等多人。

   知识密度高：既要懂商务，又要懂技术、行业、竞品、方案。

   业绩导向强：持续跟进结果、追转化、控风险。




    6、深信服的主要业务

   核心赛道：企业级网络安全 + 云计算 + AI + 物联网，A 股上市（300454）。

   三大板块：


1. 深信服智安全（防火墙、VPN、零信任、安全 GPT、XDR 等）

2. 信服云（超融合、私有云、桌面云、AI 算力平台）

   战略：AI First，安全 GPT 垂类大模型领先，服务政府、金融、教育、医疗、运营商等超 10

    万企业客户。




    7、深信服市场岗位独特不同点


1. 纯 To B 高价值：做千万级政企项目，接触高层，成长天花板高。

2. 技术 + 商务双强：不是 “喝酒销售”，是解决方案型市场，靠专业赢单。

3. 培养体系完善：新云计划 + 一对一导师 + 训战结合，应届生第一年不轻易淘汰。

4. 文化简单平等：无办公室政治、不叫总、不论资排辈、机会公平。

5. 成长快车道：海燕计划破格提拔，2-3 年可成骨干，管理者大量来自校招。

6. 赛道长期红利：网络安全 + 云计算 + AI，高研发投入，产品力强，好卖、好做、好成长。




    8、什么是市场经营思维（产品需求运营是深信服市场人员的独特价值），我们更像是市场

    经营者而不是“只会做项目的销售”
    1. 核心定位：从 “卖产品” 升级为 “卖经营方案”

    普通销售只盯着 **“我有什么产品，客户要不要买”（被动交易）；而产品需求运营 **

    （经营者）关注的是 **“客户业务怎么跑，我如何用产品帮客户提效”**（主动经营）。

    横向看（产品价值点）：你的产品不是单一的防火墙或云平台，而是 **“多模态交互”、

    “数据大屏”、“远程会议”**。

    纵向看（销售场景）：你的客户痛点不是 “缺设备”，而是 **“常态化智慧课堂怎么开”、

    “区县级数据怎么管”、“突发应急怎么救”**。

    结论：你卖的不是软件，而是解决教育场景下教学、管理、应急全流程的 “经营能力”。

    这就是 “经营者” 的视角。

    2. 决策链路：从 “搞定一人” 到 “全链路渗透”

    普通销售往往只对接 IT 主任（买设备的人）；图中的适宜人群列揭示了深信服市场人员的

    独特打法——穿透式经营：

   教学侧：学科教师、教研组长（用产品的人）。

o   落地举措：联合教育厅做 “双减”、办创新大赛、推教材配套。

o   你的价值：你不仅是供应商，更是教育局教学改革的合作伙伴。
   管理侧：校长、教导主任（做决策的人）。

o   落地举措：智慧数据分析大屏、校长决策驾驶舱。

o   你的价值：你帮校长解决了数据可视化和管理效率的问题，让校长看到了政绩。

   教研 / 应急侧：教研员、电教馆（规则制定者）。

o   落地举措：跨校教研共同体、应急 SOP 手册。

o   你的价值：你帮教育局建立了行业标准和应急机制。
