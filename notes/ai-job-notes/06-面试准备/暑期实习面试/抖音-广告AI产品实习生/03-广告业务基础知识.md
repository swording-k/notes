## 二、广告变现基本逻辑

### 1. 三方角色

| 角色 | 谁 | 目的 |
|------|------|------|
| **用户** | 看抖音的C端用户 | 消费内容，产生流量 |
| **平台**（抖音） | 连接广告主和用户 | 卖流量给广告主 |
| **广告主** | 投放广告的商家 | 获得转化/曝光 |

### 2. 变现公式

```
广告收入 = 流量 × 单次变现能力
        = DAU × 人均曝光次数 × CTR × CPC/CPM
        ≈ 千次曝光收入 (eCPM)

或更直观：
广告收入 = 展示量 × eCPM / 1000
```

## 三、核心广告产品形态

### 1. 信息流广告
- **位置**：抖音/今日头条 信息流中夹杂
- **形式**：原生视频/图文
- **特点**：最主流、最赚钱
- **计费**：CPC/CPM/oCPM

### 2. 开屏广告
- **位置**：App启动后的第一屏
- **特点**：曝光大、价格贵、品牌广告主最爱
- **计费**：CPD（按天计费）/CPM

### 3. 搜索广告
- **位置**：抖音搜索结果中夹杂
- **特点**：意图明确、CPC高、转化率高
- **计费**：CPC / oCPC

### 4. 直播广告
- **位置**：直播间引流、福袋、贴片
- **特点**：实时性强，转化链路短

## 四、核心指标体系（面试必背·带权威公式）

### 1. 客户侧六大指标

| 指标 | 全称 | 计算公式 | 含义 |
|------|------|---------|------|
| **CTR** | Click-Through Rate | 点击量 / 展现量 | 点击率，衡量吸引力 |
| **CVR** | Conversion Rate | 转化量 / 点击量 | 转化率，衡量转化效率 |
| **CPC** | Cost Per Click | 消费量 / 点击量 | 单次点击成本 |
| **CPA** | Cost Per Action | 消费量 / 转化量 = CPC / CVR | 单次转化成本 |
| **CPM** | Cost Per Mille | (消费量/展现量)×1000 | 千次曝光成本 |
| **ROI** | Return On Investment | 订单额 / 消费量 | 投资回报率 |
| **ROAS** | Return On Ad Spend | GMV/广告成本 | 广告投资回报 |

### 2. 平台侧核心指标

| 指标 | 含义 | 计算 |
|------|------|------|
| **eCPM** | Effective CPM，每千次曝光的预期/实际收入 | 见下方详述 |
| **填充率** | 广告请求中有多少被填充 | 填充数/请求数 |
| **RPM** | 每千次页面浏览的收入 | 收入/页面浏览×1000 |
| **ARPU** | 每用户平均贡献收入 | 总收入/总用户数 |

### 3. eCPM 的两种计算方式（重要！）

**正推公式（广告主视角）**：
```
eCPM = 预估点击率(pCTR) × 预估转化率(pCVR) × 目标转化出价(Bid) × 1000
```

**反推公式（媒体视角）**：
```
eCPM = (广告总费用 / 广告展示量总数) × 1000

示例：广告总收入 700 美元，展示量 200000 次
eCPM = (700 / 200000) × 1000 = 3.5 美元
```

### 4. oCPM 计费机制（VCG第二价格拍卖）

```
oCPM实际计费 = 下一位广告的eCPM + 0.01

其中：
- pCTR：系统预估广告被点击的概率
- pCVR：系统预估点击后转化的概率
- Bid：广告主设定的目标转化出价
- 0.01：防止计费为0的最小单位
```

**面试要点**：oCPM是用CTR/CVR模型 + 第二价格拍卖机制，让广告主只要设定转化目标成本，平台自动优化单次曝光报价。

## 八、广告系统核心子系统

```
广告主
  ↓
广告投放平台（巨量引擎AD后台）
  ↓
广告系统（定向、出价、召回、排序）
  ↓
用户侧展示（抖音APP）
  ↓
转化数据回流
  ↓
归因、报表、BI分析
```

### 核心子系统清单
1. **客户管理CRM**：广告主开户、资质、充值
2. **投放平台**：广告主自助创建广告计划
3. **定向系统**：人群标签、兴趣定向、Lookalike
4. **竞价系统**：eCPM计算、实时竞价（RTB）
5. **召回系统**：广告池选择
6. **排序系统**：CTR/CVR模型预估
7. **创意系统**：素材管理、A/B测试、优选
8. **归因系统**：转化归因（数据回传）
9. **报表系统**：BI看板、效果分析
10. **客服系统**：销售对接、问题处理

## 九、面试可能的业务问题（精选）

### Q1：抖音广告是怎么变现的？
**答题框架**：
> 抖音把用户流量通过广告形式变现，主要有信息流、开屏、搜索、直播、电商等多种形式。广告主通过巨量引擎AD后台自助投放，按CPM/CPC/CPA/oCPM计费，本质是\"流量×效率\"。商业化是字节最赚钱的部门，2024年集团总收入1400亿美元。

### Q2：你知道哪些广告核心指标？（必背）
**答题框架**：
> **客户侧**：CTR、CVR、CPC、CPA、CPM、ROI、ROAS
> **平台侧**：eCPM、填充率、RPM、ARPU
> **oCPM** = 预估CTR×预估CVR×目标出价×1000（用于系统排序）

### Q3：解释 eCPM 和 oCPM 的区别（高频题）
**答题框架**：
> - **eCPM** 是\"有效千次曝光成本/收入\"，反映每个曝光机会的价值，是平台排序广告的核心指标
> - **oCPM** 是智能出价模式，广告主设定目标转化成本，平台用 pCTR×pCVR×Bid 自动优化每次曝光报价
> - 实际计费：oCPM实际 = 下一位广告eCPM + 0.01（VCG二价拍卖）

### Q4：CRM 团队在广告业务里干什么？
**答题框架**：
> 销售/运营/管理者通过CRM系统管理广告主账户、跟进线索、查看数据、销售线索分配。CRM AI 是用AI重新定义这个工作流，把分散在多套系统的客户数据、广告知识、营销策略重新组织，通过自然语言交互完成。

### Q5：知道字节商业化最近有什么大动作？
**答题框架**：
> 1. 即创升级：2024年发布全量DOU+产品升级，结合AIGC能力升级商家短视频创作
> 2. AI数字人：成为商家降本增效的明星产品
> 3. 巨量引擎2025年持续投入AI广告产品

### Q6：抖音电商GMV 2024是多少？
**答题框架**：
> 抖音电商2024年GMV突破3.5万亿元，仅次于阿里、京东、拼多多，是电商行业第四极。
