## 一、即创：抖音集团旗下AIGC创意工具（真实案例）

### 产品定位
**AIGC创意工具**，为品牌定制从内容生产到投放管理的全链路AI解决方案。

### 核心能力（最新）
```
内容生产侧：
  ✅ 脚本自动生成（输入卖点→多条候选脚本）
  ✅ 口播稿生成（适配不同达人风格）
  ✅ 视频生成（脚本→自动生成短视频）
  ✅ 数字人生成（定制形象自动出镜）
  ✅ AIGC广告创意（样式+文案+素材）

投放管理侧：
  ✅ 与巨量引擎AD后台打通
  ✅ 实时效果数据反馈
  ✅ 智能优选最佳素材
```

### 关键事件
- **2024年发布全量DOU+产品升级版本**
- 结合AIGC能力升级商家短视频创作体验
- **2025年继续投入**：覆盖脚本、口播稿、视频、数字人

### 面试话术
> 我了解即创是抖音集团旗下的AIGC创意工具，能为品牌定制从内容生产到投放管理的全链路AI解决方案。2024年发布了全量DOU+产品升级，重点升级了AI视频和数字人能力。我之前也用类似的AIGC工具（如 Cursor、Midjourney），对AI创意工具有实战体感。

## 三、五大核心落地场景（重点）

### 1. AIGC 创意（最热）⭐⭐⭐
**做什么**：用大模型自动生成广告文案、图片、视频素材

**典型能力**：
- 文案生成：产品卖点 → 多种风格文案
- 图片生成：商品图 → 场景化广告图
- 视频生成：脚本 → 自动剪辑短视频
- **数字人**：真人形象→ AI数字人代言
- 智能改图：一张图 → 多尺寸多版本

**抖音真实产品**：
- **即创**：AIGC创意工具
- **AIGC数字人**：可定制形象自动出镜（商家降本增效明星产品）
- **多尺寸衍生**：一张主图生成多平台适配

**面试话术**：
> 我理解AIGC广告创意的核心价值是\"提升素材产能+降低创意成本\"。比如即创的AI数字人功能，让商家不需要请真人代言就能产出大量视频内容，对中小商家特别友好。

### 2. AI推荐/搜索广告变现
**做什么**：用大模型+推荐系统优化广告匹配

**典型能力**：
- Query理解：用户搜索意图精准识别
- 创意优选：千人千面动态优选
- 上下文理解：长query/口语化query
- 多模态匹配：图、视频、文案的跨模态匹配

**抖音实际产品**：
- 抖音搜索广告
- AI驱动的eCPM提升

**面试话术**：
> 搜索广告的eCPM提升空间来自\"意图理解精度\"，AI可以理解口语化query、上下文query、视觉query，让广告和用户的匹配更精准。

### 3. 智能销售（CRM AI）⭐⭐⭐
**做什么**：AI辅助销售跟进客户

**典型能力**：
- 智能线索评分
- AI写客户跟进邮件/话术
- 客户画像自动整理
- AI销售对话助手
- 智能客服、自动答疑

**抖音实际产品**：
- CRM AI 工作台（JD提到的）
- Agent/Skill 调用
- Memory 沉淀

**面试话术**：
> 销售场景的AI价值是\"让新手销售=老销售\"。CRM AI把老销售的经验沉淀为Skill，新人也能用AI拿到顶级销售能力。

### 4. AI智能投放优化
**做什么**：让AI帮广告主跑广告

**典型能力**：
- 智能出价（OCPM/oCPC）
- 智能定向（自动人群定向）
- 创意A/B测试自动化
- 异常检测/自动赔付
- 智能诊断（账户问题识别）

**面试话术**：
> AI投放优化的本质是\"用模型替代人做高频决策\"，在每次曝光决策中选最优，提升ROI。

### 5. BI Agent / 智能分析
**做什么**：用AI替代人工查数、写报告

**典型能力**：
- 自然语言查数据
- 自动生成BI看板
- 异常波动解释
- 趋势洞察报告

**面试话术**：
> BI Agent把\"分析师写SQL\"变成\"运营说人话\"，门槛降一个数量级。

## 四、AI产品落地方法论（面试高频）

### 1. 评估场景价值的4个维度

```
价值 = (频次 × 痛点) × (AI能力 × 数据可得性) - 风险
```

### 2. 落地步骤
1. **场景选择**：高频、痛点、数据可得
2. **能力边界**：AI能做什么不能做什么
3. **MVP设计**：人机协同开始，AI兜底
4. **效果度量**：转化率、效率、满意度
5. **规模化**：从1场景到N场景

### 3. 三大风险（面试官爱问）
- **幻觉**：AI生成错误信息（广告里编造卖点）
- **公平性**：定向导致的歧视问题
- **可控性**：AI决策可解释、可干预

### 4. 三种典型AI产品架构

```
Level 1：Copilot（副驾） - AI辅助人决策
  例：智能客服AI提示，AI写作辅助

Level 2：Agent（智能体） - AI自主完成任务
  例：CRM AI 工作台、AIGC素材生成

Level 3：Multi-Agent（多智能体） - 多AI协同
  例：营销自动化、多角色协同
```

## 七、面试必问题目及答案思路

### Q1：你怎么理解AIGC对广告行业的变革？
**答题框架**：
1. 创意生产从\"人工\"→\"AI生成+人工筛选\"
2. 个性化水平从\"分人群定向\"→\"千人千面个性化生成\"
3. 创意测试从\"小规模A/B\"→\"全自动化A/B\"
4. 成本结构变化：固定成本高、边际成本低
5. **举例**：即创让商家一键生成多条创意，A/B测试规模化成为可能

### Q2：抖音AIGC广告相比传统方式的优势？
**答题框架**：
1. **产能**：单素材生成速度提升10-100倍（AI工作流）
2. **成本**：人力成本下降70%+
3. **个性化**：千人千面成为可能
4. **测试**：A/B测试成本下降，规模化A/B成为可能
5. **数字人**：商家不需要请代言，AI数字人降本增效

### Q3：AI Agent 在 CRM 中如何重构工作流？
**答题框架**：
1. 入口统一化：自然语言替代多入口
2. 决策智能化：AI辅助判断/自动决策
3. 流程自动化：AI主动协调多步任务
4. 经验沉淀化：Skill/Memory 让经验复用
5. **举例**：让销售用一句话调取客户数据+生成跟进话术+自动安排复盘

### Q4：你认为AI广告产品的难点是什么？
**答题框架**：
1. **幻觉风险**：AI生成虚假卖点/违禁内容
2. **质量参差**：AI生成质量不稳定
3. **客户教育**：广告主不熟悉AI工具
4. **合规审核**：AI生成内容审核难度高

### Q5：如何设计一个AIGC广告创意产品？
**答题思路**：
```
1. 用户：广告主/投放人员
2. 场景：每条广告计划需要 5-10个素材
3. 痛点：人力创作慢、成本高、个性化难
4. 方案（即创思路）：
   - 输入：商品图+卖点文案
   - AI能力：生成多风格多尺寸素材
   - 输出：可投放素材包
5. 核心指标：
   - 素材生成效率提升比
   - AI素材CTR/CVR表现
6. 风险：合规审核、虚假宣传、A/B验证
```

### Q6：你用过即创吗？体验如何？
**答题思路**：
> 虽然没在生产环境用过，但我了解即创的核心能力，包括脚本生成、视频生成、数字人。我也用类似的AIGC工具（如Midjourney、Cursor）做过实践，对AI创意工具的能力边界、用户体验、Prompt调优都有体感。

### Q7：你对 Agent/RAG/Transformer 原理熟悉吗？
**答题思路**：
> - **Transformer**：自注意力机制，多头注意力，Encoder-Decoder架构
> - **GPT vs BERT**：GPT是单向（Decoder-only），BERT是双向（Encoder-only）；GPT更擅长生成，BERT更擅长理解
> - **RAG**：检索增强生成，先搜知识库再让LLM基于检索内容生成，避免幻觉
> - **Agent**：LLM + 工具调用 + 任务规划 + Memory
