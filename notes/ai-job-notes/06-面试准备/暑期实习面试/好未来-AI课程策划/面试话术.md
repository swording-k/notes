## 二、技术问题

### Q5：什么是 Token？为什么重要？

**参考答案**：
```
Token 是大模型处理文本的最小单元。

对于中文来说，通常 1 个汉字约等于 1-2 个 Token。Token 决定了：
1. 模型的上下文长度限制
2. 模型的计算成本
3. 输入输出的效率

理解 Token 概念对于 Prompt 工程和成本控制很重要。
```

---

### Q6：什么是 RAG？解决什么问题？

**参考答案**：
```
RAG = Retrieval-Augmented Generation（检索增强生成）

解决的问题是：让大模型知道最新或私有的知识。

工作流程是：
1. 把文档切分成小块
2. 向量化后存入向量数据库
3. 用户提问时，检索相关内容
4. 把检索内容和用户问题一起发给大模型
5. 生成回答

局限性是：检索质量依赖切分效果，向量召回有误差，需要优化。
```

---

### Q7：什么是 Agent？和 RAG 有什么区别？

**参考答案**：
```
Agent = 大模型 + 工具 + 记忆 + 规划

核心能力是让 AI 能执行多步任务，而不只是生成文本。

以 ReAct 模式为例：
- Thought：AI 思考下一步做什么
- Action：执行一个动作（查资料、计算等）
- Observation：观察结果
- 循环直到任务完成

RAG 和 Agent 的区别：
- RAG 是知识增强，让 AI 知道更多信息
- Agent 是任务执行，让 AI 能调用工具完成复杂任务
- 两者可以结合：Agent 调用 RAG 来检索知识
```

### Q9：如何理解"将人的经验沉淀为规则"？

**参考答案**：
```
这是一个闭环思维：

1. 观察人工怎么做 → 梳理流程
2. 把经验解构成节点 → 形成 SOP
3. 把规则固化为流程 → 用工具执行
4. AI 执行 + 人工审核 → 保证质量
5. 结果反哺规则优化 → 形成闭环

这个过程需要：
- 业务理解：知道什么是对的
- 技术能力：能把规则转成工具
- 质量意识：有人工兜底机制

我觉得这个思路很有价值，也是 AI 落地到教育场景的关键。
```
