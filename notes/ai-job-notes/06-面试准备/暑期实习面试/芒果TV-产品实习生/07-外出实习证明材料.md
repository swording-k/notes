## 二、实习内容（与专业培养目标一致性说明）

本人就读于**计算机科学与技术**专业，培养目标定位于培养具备扎实计算机理论基础、掌握现代软件工程方法、能将人工智能技术与行业场景相结合的复合型工程技术人才。本次实习内容与本人的专业培养目标**高度一致**，具体体现在以下方面：

### 1. 实习内容与专业的关联

| 实习内容 | 与专业的对应 |
|----------|--------------|
| 产品需求分析与功能设计 | 软件工程方法论、系统分析能力 |
| 跨团队协作与项目管理 | 软件项目管理、沟通协调能力 |
| 数据驱动产品优化 | 数据分析、用户行为建模 |
| AI工具在产品研发中的应用 | 人工智能、大模型应用 |
| 行业竞品分析 | 信息检索、技术调研能力 |
| 撰写产品需求文档（PRD） | 技术文档写作、需求工程 |

### 2. 实习岗位的具体工作内容

#### （1）需求调研与产品设计
- 深入理解视频内容业务场景与用户需求
- 完成需求分析、竞品调研和产品方案设计
- 运用 Axure/Figma 工具输出原型图，撰写高质量 PRD 文档
- 调研对象：爱奇艺、腾讯视频、B站等竞品平台

#### （2）项目推进与跨团队协同
- 作为产品需求方，协调设计、前端、后端、测试等多方资源
- 制定项目计划并跟踪落地节奏，确保按时交付
- 学习互联网产品从 0 到 1 的完整研发流程

#### （3）数据驱动产品优化
- 关注产品上线后的数据表现
- 学习使用友盟、神策等数据分析工具
- 通过漏斗分析、A/B测试等方法持续优化产品体验

#### （4）AI 工具在产品研发中的探索
- **这是本人在实习中的核心差异化优势**，也是与计算机专业最紧密结合的部分
- 主动探索大模型（如通义千问、文心一言、ChatGPT、Cursor 等）在以下环节的应用：
  - 用户调研：使用 AI 工具进行用户评论情感分析
  - 需求文档：使用 AI 协助撰写 PRD 与竞品分析
  - 原型设计：使用 AI 工具生成原型初稿
  - 数据分析：使用 AI 协助数据报表整理与洞察提取
- 推动团队智能化工作流建设，提升研发效率

### 3. 与专业培养目标的契合点

本人专业培养的核心能力包括：**编程能力、系统设计能力、算法能力、AI应用能力、产品工程能力**。本次实习涵盖了除纯编码外的全部核心能力点，特别是 **AI+产品+行业** 的复合型实践机会，这正是当前计算机专业人才培养倡导的"AI赋能行业"方向。

## 三、实习计划

### 总体目标

通过为期 3 个月的产品实习，深入了解互联网视频行业的产品研发全流程，结合自身计算机与AI技术背景，形成 **"懂技术 + 懂AI + 懂产品 + 懂行业"** 的复合型能力，为未来进入大厂从事AI产品/Agent开发岗位奠定基础。

### 分阶段计划

#### 第一阶段：快速学习期（第1个月）

**目标**：熟悉团队、熟悉业务、建立协作关系

| 周次 | 主要任务 |
|------|----------|
| 第1周 | 熟悉团队工作方式与日常工作流；学习视频行业基础知识；完成入职培训 |
| 第2周 | 参与需求评审（旁听+记录）；学习产品文档模板；调研竞品（爱奇艺、腾讯视频、B站） |
| 第3周 | 开始承担小型产品需求；学习撰写PRD、绘制原型；与设计/研发建立协作 |
| 第4周 | 独立完成1个完整小型产品需求；月度复盘 |

**学习重点**：
- 视频行业基础（内容推荐算法、用户增长策略、会员订阅体系）
- 产品方法论（用户调研、需求分析、功能设计）
- 工具使用（Axure/Figma、Jira/TAPD、神策/友盟）

#### 第二阶段：实践产出期（第2个月）

**目标**：独立负责产品功能，提升跨部门协作能力

| 工作内容 | 预期产出 |
|----------|----------|
| 独立负责1-2个完整产品功能 | 完整的PRD文档与原型图 |
| 跨部门协作（设计、研发、运营、测试）| 需求按时交付 |
| 学习数据分析方法 | 1份数据分析报告 |
| 探索AI工具在产品研发中的应用 | 1-2个AI提效实践案例 |

**学习重点**：
- 数据分析（漏斗分析、A/B测试、用户行为分析）
- AI工具深度使用（Prompt工程、AI辅助PRD写作）
- 视频行业进阶（创作者生态、内容运营）

#### 第三阶段：价值证明期（第3个月）

**目标**：形成可量化的项目成果，完成实习复盘

| 工作内容 | 预期产出 |
|----------|----------|
| 完成1-2个有数据成果的产品项目 | 简历可写的项目经验 |
| 输出AI工具应用案例 | 团队内部最佳实践文档 |
| 准备转正答辩（如适用） | 答辩材料 |
| 实习复盘与下阶段规划 | 完整复盘报告 |

### 必学工具清单

- **原型设计**：Axure / Figma
- **需求管理**：Jira / TAPD / 禅道
- **数据分析**：友盟 / 神策 / Google Analytics
- **文档协作**：语雀 / 飞书 / 钉钉
- **AI工具**：通义千问、文心一言、ChatGPT、Cursor、Trae

### 持续学习计划

- **视频行业动态**：36氪、虎嗅、晚点LatePost、艺恩数据、骨朵网络影视
- **产品方法论**：人人都是产品经理、俞军产品方法论
- **AI视频技术**：可灵AI、智谱AI、字节AI Lab、Runway、Pika

1. **项目经验**：1-2个完整的产品项目经验，可写入简历
