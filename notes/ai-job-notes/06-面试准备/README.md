## 五、目录规范

1. **按阶段分**：`暑期实习面试/` 与 `秋招面试准备/`，不把新岗位直接放在 `06-面试准备/` 根目录。
2. **按「公司-岗位」建目录**：如 `美团-AI产品Builder/`，岗位名写清楚。
3. **每个岗位目录尽量有 `00-` 开头的入口文件**：岗位分析 / 目录说明。
4. **通用材料放阶段根目录**：简历、投递策略、项目双视角问答。
5. **面试结束后保留材料**，在阶段索引里把状态改为「已结束」，不直接删除。
