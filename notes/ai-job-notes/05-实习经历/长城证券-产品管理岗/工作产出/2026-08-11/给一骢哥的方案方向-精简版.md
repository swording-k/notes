# 完整轻量项目管理方案方向

> 提交人：杨锟 ｜ 日期：2026-08-11 ｜ 背景：基于 新对齐的方向

## 一、一句话结论

把现有的飞书群聊项目管理智能体，从"禅道前置的沟通沉淀"升级为**直接在群里完成项目管理的轻量系统**——需求、任务、分配、工时、排期、决策全部在群里一句话搞定，不再依赖禅道填表。禅道仅在公司合规要求时留一个"公共项目"做壳。

## 二、为什么要做（现状痛点）

- **禅道填表太繁琐**：每建一个需求/项目都要填一堆表单，团队觉得麻烦、不愿用。
- **讨论与决策无留存**：日常需求靠微信私聊、口头对接分配，做完只在禅道记个工时；"当时为什么这么定"没人记得，新人接手很难理解背景。
- **能力已具备大半**：我们已在飞书群里跑通一个智能体，能自动识别群聊里的需求、记录决策、生成周报，已经具备了"聊天即任务"的能力，只差把"管理动作"补完整。

## 三、方案是什么

以飞书群聊为唯一入口，智能体把群里的自然语言讨论实时转成结构化项目数据，底层用飞书多维表格存储。

本质上就是**飞书项目"聊天即任务"的轻量自建版**——不采购、不迁移、零额外成本，但把禅道最烦的"填表"环节省掉了。

不同人看不同内容，不靠复杂权限，而是用多维表格的**视图**实现：

- 「成员」：每人能看自己负责的
- 「任务」：根据多种方式排版管理项目任务
- 「决策日志」：看团队决策历史

## 四、这个系统具体怎么跑（结合咱们的真实工作流）

以咱们团队现在实际的工作方式为例，一个需求从产生到周报，全程在飞书群里走完：

1.开新项目：在群里聊开新项目“商机广场”，“项目”板块会出新项目

**2.需求产生**：您和开发在群里聊、私聊、或开会讨论新需求 → Agent 自动识别，在任务表生成一条记录（现已跑通）

**3.决策拍板**：群里说"就按 A 方案做" → Agent 记一条决策日志，关联到对应任务（现已跑通）

**4.任务分配**：您说"@张三 负责 X" → Agent 自动把"张三"写进任务表的「责任人」字段 ★ 本期新补的能力

**5.执行跟踪**：开发进度有变化，在群里说一句，或 @Agent 查／改状态 → Agent 更新任务状态（现已跑通）

**6.智能体主动反馈**：每天定时推送日报（提醒需要补上的字段等等），每周五 Agent 自动汇总周报"谁在做什么、卡在哪"，发到群里（现已跑通）

这 5 步连起来就是一个**完整闭环**——从聊需求到做任务，全程在群里完成，不用再登录禅道填表。

**Phase 1（刚实现）**：

- 需求识别 → 任务表
- 人员分配 → 责任人/协同人字段
- 决策记录 → 决策日志表
- 每日/每周报告 → 基于任务表+决策日志表聚合

**Phase 2（正在尝试实现）**：在基础上，再加工时填报、排期／里程碑、进度量化（完成率），让管理更精细。
