## 【已查实事实（直接用，别再编）】

### 一、深信服公司业务（2025 年报）
- 定位：A 股网络安全头部，已变成"安全 + 云"双引擎。
- 2025 营收 **80.43 亿**（+6.96%），归母净利 **3.93 亿**（+99.52%），员工 **7282 人**。
- 业务构成（反直觉点）：云计算及 AI 基础设施 **40.1 亿（49.86%）** 首次超过网络安全 **35.4 亿（44.01%）**；基础网络 4.93 亿（6.13%）。
- 品牌：深信服智安全 + 信服云；子公司**信锐技术**做数通。
- 客户：超 10 万家企业级用户，政府及事业单位约 39%、企业约 51%、金融及其他约 10%。
- AI 布局（重点）：安全 GPT、CoStrict AgentBuilder（智能体构建）、DeepSeek 承载方案、AI 算力网关、零信任 aTrust、安全托管 MSS。
- 产品举例：AF 下一代防火墙、aTrust 零信任、EDR 终端安全、数据安全态势感知、超融合 HCI、EDS、桌面云 aDesk、托管云。

### 二、美团（对比用，显格局）
- 2025 营收 **3648.5 亿**（+8.1%），但因即时零售价格战**由盈转亏，净亏 233.5 亿**；研发投入 260 亿（+23%），"零售 + 科技"。
- 体量约是深信服 **45 倍**；但深信服盈利稳、在自己赛道是龙头。两者是不同量级的"大"。

### 三、售前产品经理岗到底是干嘛的
- 一句话：在**签单前**，把公司复杂的安全 / 云产品能力，翻译成客户（政府 / 金融 / 企业 IT 负责人）**愿意买单的解决方案**，并支持销售拿下订单。是产品与销售之间的桥梁，偏"商业化落地 + 客户侧技术顾问"。
- **具体场景（背这个：某三甲医院要过等保 + 防勒索）**：
  1. 现场调研：画网络拓扑，找"边界没防护、终端裸奔、日志没审计"等缺口；
  2. 出方案建议书：AF（边界）+ EDR（防勒索）+ 行为管理 + 日志审计 + 态势感知，画部署图，逐条对照等保三级技术要求；
  3. 现场演示：模拟勒索病毒攻击当场拦下；
  4. 商务：给"买断 + 3 年服务费"报价，或对比"全托管 MSS"模式；
  5. 投标 / 谈判：写技术标。
- **为什么客户不自己搞（甲方乙方分工）**：多数政企 IT 只是运维，不造安全产品（类比医院不造 CT 机）；即便金融机构有安全团队，也是甲方"运营 + 合规 + 管供应商"，产品来自乙方厂商；合规刚需（等保 2.0 / 关基 / 数据安全法）强制采购；MSS 连运维都外包。
- **"方案"里面有什么（方案建议书 / 建设方案模块）**：客户现状 / 需求与目标 / 推荐产品组合 / 部署架构图 / 合规映射 / 价值说明 / 商务模式。
- **售前 vs 交付边界**：售前在签单前讲清楚方案让客户买；交付团队签单后真去部署加固。售前卖"决策依据"，不是"施工手册"。

### 四、薪资天花板（实话）
- 20 万起；0–3 年约 15–30 万，5 年以上资深约 40–50 万 / 年。
- 100 万是真的，但来自管理线（售前主管 → 总监 → 解决方案副总，对标销售总监）或专家线（行业首席，AI 售前专家百万起步），需 8–15 年，非自动。
- 纯基层售前天花板最低。

### 五、LSL 说明
"LSL" 是用户首条消息口误（原话"To B lsl 产品经理岗位"），公开资料查无此缩写。深信服售前按产品线（安全 / 云 / 数通）或行业线（政府 / 金融 / 教育 / 医疗）划分，**没有 LSL 这条线**。按通用 To B 售前准备即可。

## 【我已准备好的答稿（可直接用）】

### 必问题 1："你会不会不选择美团，来我们公司？"
> 美团是很强的 offer，平台大、我也尊重，但它偏消费互联网的产品 track。深信服吸引我的是两点：一是它正好在企业级安全 / 云 + AI 转型的节点上（安全 GPT、AgentBuilder、DeepSeek 承载方案），这和我自己做的 AI Agent 方向、以及券商 To B 产品的经历是对得上的；二是售前产品经理这个岗能让我直接面对客户、做方案落地，这是我目前最想补的能力——比在纯产品岗对着研发画原型，更快长成企业级产品的操盘手。所以不是随便来面一面，是我确实想走企业 AI 这条路时，这个岗是少有的对口起点。

（命门：底色得是真想走企业 To B / 企业 AI 这条路，否则显假。）

### 必问题 2："你对深信服的理解是怎样的，为什么想投递？"
> 我理解深信服已经从"安全公司"变成"安全 + 云"双引擎——2025 年云计算及 AI 基础设施收入 40 亿、首次超过安全的 35 亿，占比约 50%。客户覆盖政府、金融、企业三大类，10 万 + 企业用户。我最感兴趣的是它现在的 AI 布局：安全 GPT、智能体构建、AI 算力网关——这些正好是我实习做 To B 产品、以及自己研究 PM Agent 时一直在想的事。投递是因为我想把"产品能力"和"客户侧落地"早期就捏在一起，售前是对新人最友好的切入点。

### 长城证券经历打通话术（杀手锏）
- 长城证券（手拉手）：把投行 / 研究的专业能力，翻译成一线客户经理用得上的协同工作流。
- 深信服售前：把深信服的安全 / 云产品能力，翻译成客户愿意买单的方案。
- 本质一样——把复杂专业能力变成对方用得上的交付物；区别只是对象从内部同事变成外部付费客户，且多了演示 / 投标 / 报价等商业化动作。

### 二面可能追问 + 答法
1. "为什么从 AI 产品 / 券商实习来做售前？" → 用打通话术，强调 To B 复杂产品落地能力通用 + 看重售前复合成长路径。
2. "售前要经常出差 / 驻外，能接受吗？" → 直接表态接受驻外，年轻阶段看重项目历练；薪酬含驻外 / 住房补贴 + 全年奖金 + 股权激励。
3. "售前和纯产品岗最大不同？" → 纯产品对内做需求画原型；纯销售主导客户签单；售前站客户现场，把复杂产品能力翻译成客户听得懂、买单的方案。
4. "讲讲深信服 / 它最近在做什么？" → 云已超安全成第一业务 + AI 布局。
5. "客户听不懂技术方案怎么办？" → 先做业务翻译：先问痛点和驱动力，再对齐方案，不堆技术名词。
