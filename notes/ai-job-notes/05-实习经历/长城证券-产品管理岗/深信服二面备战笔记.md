## 0. 先澄清：LSL 是什么（已作废）

"LSL" 来自用户首条消息"To B lsl 产品经理岗位"，疑为口误 / 语音转文字乱码。公开资料查无此缩写，深信服售前通常按**产品线（安全 / 云 / 数通）**或**行业线（政府 / 金融 / 教育 / 医疗）**划分。本笔记按通用"To B 售前产品经理"准备，更稳，不依赖不存在的缩写。

## 1. 公司业务（背这几个数，显你做了功课）

### 深信服（300454.SZ）
- **定位**：A 股网络安全头部企业，但已变成"安全 + 云"双引擎。
- **2025 年报**：营收 **80.43 亿**（+6.96%），归母净利 **3.93 亿**（+99.52%），员工 **7282 人**。
- **业务构成（反直觉点）**：云计算及 AI 基础设施 **40.1 亿（49.86%）** 首次超过网络安全 **35.4 亿（44.01%）**；基础网络及物联网 4.93 亿（6.13%）。→ 它早不是纯安全公司。
- **品牌**：深信服智安全（SANGFOR SECURITY）+ 信服云（SANGFOR CLOUD）；子公司**信锐技术**做数通。
- **客户**：超 10 万家企业级用户，覆盖政府及事业单位（约 39%）、企业（约 51%）、金融及其他（约 10%）。
- **AI 布局（重点挂，和你 PM Agent 背景对口）**：安全 GPT / 大模型安全护栏、CoStrict AgentBuilder（智能体构建）、DeepSeek 承载方案、AI 算力网关、零信任 aTrust、安全托管 MSS。
- **产品举例**：AF 下一代防火墙、aTrust 零信任、EDR 终端安全、数据安全态势感知、超融合 HCI、分布式存储 EDS、桌面云 aDesk、托管云。

### 美团（对比用，面试官若问"为啥不选美团"时显格局）
- **2025**：营收 **3648.5 亿**（+8.1%），但因即时零售价格战**由盈转亏，净亏 233.5 亿**；研发投入 260 亿（+23%），"零售 + 科技"。
- **体量约是深信服的 45 倍**；但深信服盈利稳、在自己赛道是龙头。两者是不同量级的"大"——美团是消费互联网平台级，深信服是企业级细分赛道龙头。

## 2. 售前产品经理到底是干嘛的（核心！被问场景就甩这个）

### 一句话
在**签单前**，把公司复杂的安全 / 云产品能力，翻译成客户（政府 / 金融 / 企业 IT 负责人）**愿意买单的解决方案**，并支持销售拿下订单。是产品与销售之间的桥梁，偏"商业化落地 + 客户侧技术顾问"。

### 具体工作场景（背这个：某三甲医院要过等保 + 防勒索）
1. **现场调研**：跟信息科主任聊，画出现有网络拓扑，找出"边界没防护、终端裸奔、日志没审计"等缺口。
2. **出方案建议书**：推荐组合——AF 下一代防火墙（边界）+ EDR 终端安全（防勒索）+ 全网行为管理 + 日志审计 + 态势感知；画部署图；**逐条对照等保三级技术要求**，写明"这套能帮你过测评"。
3. **现场演示**：带测试设备模拟勒索病毒攻击，当场拦下，让客户"眼睛看到能防住"。
4. **商务**：给"买断授权 + 3 年服务费"报价框架，或对比"全托管 MSS（连运维都外包给我们 7×24 监测）"模式。
5. **投标 / 谈判**：进入采购流程，写技术标。

### 为什么客户不自己搞（甲方乙方分工，回答"别的公司不是有安全人员吗"）
- 多数政企的 IT 只是**运维**，不造安全产品（类比医院不自己造 CT 机，买 GE / 联影的）。
- 即便金融机构有安全团队，也是甲方"安全运营 + 合规 + 管供应商"角色；安全引擎、威胁情报、产品迭代来自乙方厂商。**甲乙方是分工，不是替代。**
- **合规刚需**：等保 2.0、关基保护、数据安全法强制采购，不是"有没有自己人"的问题。
- **托管 MSS**：很多中小客户连运维都缺，直接把安全运营外包给厂商云端安全运营中心——买服务不是买人。

### "方案"里面有什么（方案建议书 / 建设方案模块）
| 模块 | 内容 |
|---|---|
| 客户现状 | 现有拓扑、设备清单、痛点、合规缺口 |
| 需求与目标 | 过等保几级 / 防什么威胁 / 预算区间 |
| 推荐产品组合 | AF + EDR + aTrust + 态势感知…各自干嘛 |
| 部署架构图 | 设备放哪、怎么接、流量怎么走 |
| 合规映射 | 逐条对照等保 / 行业监管要求 |
| 价值说明 | 解决什么风险、提升什么效率 |
| 商务模式 | 买断 / 订阅 / 托管 MSS，报价框架 |

### 售前 vs 交付边界（回答"提供一套加固方案吗"）
**售前在签单前工作；真正的"加固"是签单后交付实施团队拿着你的方案去物理执行。** 你交付的是"买什么、怎么摆、为什么行"的提案 + 演示 + 报价——卖的是**决策依据**，不是施工手册。

> "美团是很强的 offer，平台大、我也尊重，但它偏消费互联网的产品 track。深信服吸引我的是两点：一是它正好在**企业级安全 / 云 + AI 转型**的节点上（安全 GPT、AgentBuilder、DeepSeek 承载方案），这和我自己做的 AI Agent 方向、以及券商 To B 产品的经历是对得上的；二是售前产品经理这个岗能让我**直接面对客户、做方案落地**，这是我目前最想补的能力——比在纯产品岗对着研发画原型，更快长成企业级产品的操盘手。所以不是随便来面一面，是我确实想走企业 AI 这条路时，这个岗是少有的对口起点。"

⚠️ 命门：你得**真想走企业 / To B 这条路**。若内心更想去美团做消费产品，这句就假，面试官闻得出来。

### Q2："你对深信服的理解是怎样的，为什么想投递？"
> "我理解深信服已经从'安全公司'变成'安全 + 云'双引擎——2025 年云计算及 AI 基础设施收入 40 亿、首次超过安全的 35 亿，占比约 50%，说明它早就不是纯安全厂商了。客户覆盖政府、金融、企业三大类，10 万 + 企业用户。我最感兴趣的是它现在的 AI 布局：安全 GPT、智能体构建、AI 算力网关——这些正好是我实习做 To B 产品、以及自己研究 PM Agent 时一直在想的事。投递是因为我想把'产品能力'和'客户侧落地'这两件事早期就捏在一起，售前是对新人最友好的切入点。"

## 5. 薪资天花板实话（别被 JD 话术带跑）

- **20 万起**；行业真实阶梯：0–3 年约 15–30 万，5 年以上资深约 40–50 万 / 年。
- **100 万是真的，但来自两条路**：①管理线（售前主管 → 售前总监 → 解决方案副总，对标销售总监）；②专家线做到行业首席解决方案专家（尤其 AI 售前，行业专家年薪"百万起步、三五百万有可能"）。
- **纯待在基层售前、不往上走，天花板反而最低**——100 万不是校招 20 万自然涨上去，是干到总监 / 顶尖专家、熬 8–15 年后的上限。
- 美团平台约 45 倍大；若纯看薪酬天花板与平台，美团大概率占优。若看企业 To B + AI + 更快客户侧成长，深信服售前是合法跳板。

## 6. 和长城证券经历打通（杀手锏话术）

- **长城证券（手拉手）**：把**投行 / 研究的专业能力**，翻译成一线客户经理用得上的协同工作流。
- **深信服售前**：把**深信服的安全 / 云产品能力**，翻译成客户（医院 / 政府 / 企业 IT 负责人）愿意买单的方案。
- **本质一模一样**——把复杂专业能力，变成对方用得上的交付物。区别只在于：长城证券对象是**内部同事**，深信服对象是**外部付费客户**，且多了演示、投标、报价等商业化动作。
- 你做过新人教学文档、产品视频、推文——这就是"运营推广 + 解决方案输出"，和售前"运营推广、解决方案提供"职责直接吻合。

## 7. 二面可能追问 + 答法

1. **"你为什么从 AI 产品 / 券商实习，想来做售前？"** → 用第 6 节串联逻辑，强调 To B 复杂产品落地能力通用 + 看重售前复合成长路径。
2. **"售前要经常出差 / 驻外，你能接受吗？"** → 直接表态接受驻外，年轻阶段看重项目历练；提一句薪酬含驻外 / 住房补贴 + 全年奖金 + 股权激励。
3. **"售前和纯产品岗最大不同？"** → 纯产品对公司内做需求设计画原型；纯销售主导客户关系签单；售前站客户现场，把复杂产品能力翻译成客户听得懂、买单的方案。
4. **"讲讲深信服 / 它最近在做什么？"** → 用第 1 节数据（云已超安全成第一业务 + AI 布局）。
5. **"客户听不懂你的技术方案怎么办？"** → 先做业务翻译：先问痛点和驱动力，再对齐方案，不堆技术名词——正是你券商经历的做法。
