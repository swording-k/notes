## 架构交付物要点（来自附件1，供快速了解）

- **定位**：公司级协同平台（即「手拉手」产品）。2025 年初务虚会由领导提出；目标"以客户为中心"，内部协同流程化 / 线上化、全流程留痕与追踪，登记协同关系 / 成果 / 贡献。
- **接入方式**：Web 端 + API。Web 经**员工中心**单点登录（SSO）+ 角色数据权限；API 用 OAuth2.0 鉴权。
- **后端**：SpringBoot 微服务；Kong 网关做网络隔离，Nginx 负载均衡，Rancher 集群多 Pod 高可用。
- **前端**：TypeScript / JavaScript + React（redux / react-router-dom / hooks）+ Ant Design + D3 / ECharts。
- **AI 能力**：AI 协同助手、AI 产业链、AI 舆情。前两者共用一套聊天 UI（不同入口调不同后端接口），AI 舆情独立 UI。AI 助手知识来自产品库 / 案例库 / 法规库，同步到 dify 本地知识库；AI 产业链、AI 舆情用公网云上数据。
- **数据**：TDSQL；经「长城方舟大数据平台」CCP 工具从大数据中间库 `data_governance`（底层源自财汇采购）采集，含新闻机构穿透表 `yq_news_org_pntt`；库部署于长城长信创集群；前端最小化数据权限、无导出功能。
- **运维**：低频访问系统；25 并发用户 TPS>34，90% 响应 <0.1s，API 响应 <0.02s。
- **与六大中心关系**：依赖员工中心做 SSO 与应用权限。
