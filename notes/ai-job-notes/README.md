## 笔记规范

**自己写的笔记必须使用 Obsidian 双链**：

```markdown
[[笔记名]]                    # 同目录
[[文件夹/笔记名]]              # 子目录
[[../上级目录/笔记名]]         # 上级目录
![[截图名.png]]               # 嵌入图片
```

- 外部网页链接用普通 Markdown 链接
- 不使用绝对路径
- `09-开源书库/` 内的教材保留原始相对链接，不批量改写

## 目录约定

1. 新笔记优先放进 `07-AI应用工程师知识/` 或 `08-AI产品经理知识/`，并回到本 README 和对应目录说明里挂链接。
2. 面试材料按「公司-岗位」建目录，放在 `06-面试准备/` 的对应阶段下。
3. 过期计划不直接删，移到 `00-学习规划/历史归档/`。
4. 读书笔记不直接改书稿；在 `07-AI应用工程师知识/` 里引用章节。
